Operational Playbook · 6 Phases

How to Use HyperFrames Pro: Step-by-Step Guide

Follow this end-to-end workflow to go from a raw script or reference video to a multi-track, voiceover-synced, cloud-rendered 1080p/4K MP4 without fighting a traditional NLE timeline.

Phase 01 · Setup ~5 min

Initialize Studio, Brand Kits & 4-Beat Prompt

Launch the HyperFrames Desktop App and establish visual consistency before generating scenes so Framey inherits your typography and palette automatically.

  • Configure a Brand Kit (colors, fonts, logo) or pick a starting template from the 1,000+ Inspirations library.
  • Use the "Your first video" composer to structure your narrative into 4 beats: Hook → Proof → Turn → Call to action.
  • Optionally complete a 2-minute Pit Crew Academy lesson inside Learn HyperFrames to pick up precise motion vocabulary (e.g., "staggered pop with overshoot").
  • Maintain up to 20 active cloud projects simultaneously for multi-client work.
Phase 02 · Storyboard STORYBOARD.md

Storyboard, Fact-Check & Reverse-Engineer References

Before burning credits on animations or voiceovers, lock the narrative structure and visual style using HyperFrames' research and reference tools.

  • Let Framey draft STORYBOARD.md and audit factual claims (Framey flags stats with "verify before air" notes and lists source citations).
  • Use /reverse-any-video to decompile an existing reference video into an editable HyperFrames project, or Video Match to clone a pacing/visual style.
  • Pull visuals via built-in image/footage search and clean up subjects with unlimited background removal.
Phase 03 · Build & Edit index.html + GSAP

Compile HTML Scenes & Click-and-Change Layers

Click "Build the video" to watch Framey (powered by Claude Sonnet 5.5) compile posed HTML scenes into index.html and boards/.

  • Wait for the Working | Locked timeline pill to finish—HyperFrames locks the timeline during agent writes to prevent race conditions.
  • Switch to Select mode and click any element on the video canvas to open the inline "Describe a change" prompt scoped directly to that DOM layer.
  • Use Draw to circle regions visually or Comment to leave timestamped feedback; inspect every nested element in the Layers panel.
Phase 04 · Audio & QA .wav + .transcript.json

Multi-Level Voiceover Synthesis & Auto Audio Ducking

Automate narration and sound design per scene so you can regenerate a single slide's voiceover without re-recording the entire video.

  • Framey invokes Used Hf generate voiceover (HeyGen / ElevenLabs) per scene, producing paired .wav and .transcript.json files for word-accurate subtitle sync.
  • Run the "Sorted out the sound" pass to align staggered music beds (Bed1–Bed5) ducked cleanly to 22% volume with fx crossfades.
  • Verify captions in the Captions tab and let Framey complete its automated "Checked the video" multi-step QA pass.
Phase 05 · Code Handoff ~/.hyperframes-studio/

Hand Off to Claude Code for Precision Engineering

When you need custom SVG charts, surgical GSAP easing curves, or Git version control, open the exact same folder in your terminal with Claude Code.

  • Click the project folder pill in Studio → Copy folder path (stored under ~/.hyperframes-studio/ with CLAUDE.md & AGENTS.md pre-installed).
  • In Claude Code, run /plugin → Marketplaces → hyperframes → Enable auto-update, then verify with /hyperframes:hyperframes.
  • Prompt direct HTML/CSS/GSAP edits and inspect them instantly in Studio or via npx hyperframes preview.
Phase 06 · Render & Share Cloud Queue

Manage Credits & Queue Unlimited Cloud Renders

Keep your laptop free for billable work by offloading final encodes to HyperFrames' cloud render farm.

  • Monitor credit burn (~468 credits / 90s; ~3,120 / 10-min video). If you hit "Out of credits" mid-project, top up or plug in a BYO HeyGen API key to continue immediately.
  • Open Export → select Render on: Cloud → choose 1080p or 4K, MP4 / WebM / MOV, and 30 fps.
  • Queue the render (~9 min for a 17.5-min 1080p MP4), close your laptop or switch projects, and send the Share link for Team Review.

// 2. Compose deterministic frames in React (Remotion):
export const Scene02 = ({ clipUrl }: { clipUrl: string }) => {
  const frame = useCurrentFrame();
  const opacity = interpolate(frame, [0, 30], [0, 1]);

    </Sequence>
  );
};
