Architecture 01 · Core Engine

Video-as-Code Compilation Pipeline

Instead of locking scenes inside a proprietary binary timeline, HyperFrames compiles every frame, animation, and audio cue into standard web assets backed by an AI agent loop.

  • Input & Storyboard: Natural-language scripts, brand kits, and verified research sources.
  • AI Orchestration (Framey): Claude Sonnet 5.5 drives scene scripting, multi-level voiceovers, and bed mixing.
  • Web Composition Engine: Standard index.html, boards/, CSS layouts, and GSAP timeline layers.
  • Cloud Render Farm: Headless cloud renderers export 1080p/4K MP4, WebM, or MOV asynchronously.

Architecture 02 · Hybrid Workflow

Studio ↔ Claude Code Bidirectional Handoff

Because every project lives locally inside ~/.hyperframes-studio/ as plain web files, you can switch freely between visual click-and-change editing and terminal-driven Claude Code automation.

  • Shared Project Hub: index.html, hyperframes.json, STORYBOARD.md, CLAUDE.md, and AGENTS.md.
  • Plugin Context: Install via /plugin → hyperframes so Claude understands the rendering engine.
  • Instant Live Sync: Code edits from Claude appear immediately in Studio or via npx hyperframes preview.

Architecture 03 · Contractor ROI

Cloud Render Offload vs. Local Hardware Lockup

For full-time developers and contractors producing client videos, local rendering is the primary throughput bottleneck. Offloading encodes to the cloud decouples video delivery from engineering work.

  • Local Open-Source Bottleneck: 10–13 min per pass × 20 iterations = 3.5–4.5 hrs at 100% CPU/GPU saturation.
  • Pro Cloud Render Queue: Queue a 1080p/4K MP4 render, close your laptop or pivot to another repo with zero local load.
  • Unlimited Exports: Iterate freely without export caps once media assets are generated.

Developer Handoff Workflow

Continuing Your Studio Project in Claude Code

Because HyperFrames Studio saves every composition as a standard local web project, you can hand the folder directly to Claude Code for precision GSAP easing, layout refactors, or data-driven overlays. (Source: handoff-claude.md)

1

Locate Project Directory

Find the local project folder inside ~/.hyperframes-studio (verify index.html and hyperframes.json exist).

2

Launch Claude Code

Open your terminal, cd directly into the project folder, and start your Claude Code session.

3

Install HyperFrames Plugin

Run /plugin → Marketplaces → hyperframes → Enable auto-update, then verify with /hyperframes:hyperframes.

4

Prompt Programmatic Edits

Ask Claude to tune GSAP animation easing, swap palettes, or inject SVG data charts directly in HTML/CSS/JS.

5

Instant Live Preview

Check the live canvas back in HyperFrames Studio or run npx hyperframes preview in a separate terminal tab.

Serve the repository locally on a 30k+ port to avoid port collisions and open in Google Chrome:

python3 -m http.server 30080
open -a "Google Chrome" http://localhost:30080

2. Automated GitHub Pages Deploy

Push changes to main to trigger the Actions workflow (actions/deploy-pages@v5):

git add .
git commit -m "Update HyperFrames Pro showcase"
git push origin main
