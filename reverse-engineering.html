End-to-End Execution

5-Step Video Reverse-Engineering Pipeline

Reproduce the exact workflow captured in our field study—from installing the official plugin to rendering a 120 BPM reel with contact-sheet verification.

Step 01 · Plugin Install

Install heygen-com/hyperframes

Install the official versioned plugin from github.com/heygen-com/hyperframes in Claude Code (or via npx skills for Cursor, VS Code, Copilot, Gemini CLI, and OpenCode).

# Claude Code (recommended):
claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes
# Enable auto-update in: /plugin -> Marketplaces -> hyperframes

# Other AI coding agents (Cursor, VS Code, Copilot, Gemini CLI, OpenCode):
npx skills add heygen-com/hyperframes
Step 02 · Frame Extraction

Extract Reference Contact Sheet (Optional Local MP4)

If reverse-engineering a downloaded reference.mp4, sample 2 frames per second into a tiled contact sheet with ffmpeg so Claude can inspect every cut, font weight, and transition directly.

# Generate a 0.5s-interval contact sheet from any reference MP4:
ffmpeg -i reference.mp4 -vf "fps=2,scale=320:-1,tile=6x6" ref-sheet.jpg
Step 03 · Decompile to STORYBOARD.md

Analyze Pacing, Palette & Hooks

Feed the reference URL or ref-sheet.jpg plus your own product screenshots into Claude Code with /hyperframes:hyperframes. Ask Claude to document exact chapter timings in STORYBOARD.md and audit color contrast.

/hyperframes:hyperframes
Analyze ref-sheet.jpg (or the reference URL).
1. Break down every chapter cut in STORYBOARD.md on a 120 BPM grid.
2. Identify the hook, proof, turn, and CTA structure.
3. Audit brand contrast (override unreadable light yellow on white).
4. Use ONLY my real product screenshots in ./assets/ — invent zero fake stats.
Step 04 · Modular HTML/GSAP Build

Compile Scenes & Inspect on localhost:3002

Claude builds modular HTML scenes (frames/01-hook.html through 05-cta.html) plus root index.html. Launch local preview to verify Lint checks and motion choreography.

npx hyperframes preview
# Opens local HyperFrames Studio on http://localhost:3002
# Check: Compositions, Lint count, Record a gesture (R), and ⌘K edits
Step 05 · Contact Sheet QA & Render

Verify sheet.jpg & Export MP4

Render a silent 15s 1920×1080 reel plus a sheet.jpg contact sheet (1 frame every 0.5s) to catch any layout glitches before adding a 120–128 BPM music track and exporting via local CLI or Pro Cloud.

# Ask Claude to render + verify via contact sheet:
"Render the 15s 1920x1080 MP4 and generate sheet.jpg (1 frame every 0.5s).
 Read sheet.jpg to verify zero text clipping, contrast issues, or broken frames.
 Then lay in ./assets/track-120bpm.mp3 with fade-in/out."
