5-Step Setup: HyperFrames Pro (£19) + Local fal.ai

Follow these five steps to wire fal.ai media generation directly into any HyperFrames Pro project directory on macOS/Linux.

Step 01

Install the HyperFrames Plugin in Claude Code

Install the official HeyGen HyperFrames plugin once so Claude Code understands index.html, boards/, and GSAP timeline rules natively.

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes
# Or for Cursor / VS Code / Copilot / Gemini CLI:
npx skills add heygen-com/hyperframes
Step 02

Open Your Pro Project Folder & Add @fal-ai/client

In HyperFrames Pro Studio, click the folder pill → Copy folder path, then install the fal.ai JS SDK and set your FAL_KEY.

cd ~/.hyperframes-studio/<your-project-folder>
npm install @fal-ai/client
export FAL_KEY="your_fal_api_key_here"
Step 03

Generate Video/Image/Voice Assets via fal.ai into assets/

Drop this reusable 20-line script (scripts/gen-fal.mjs) into your project so Claude Code can generate pay-per-second B-roll or images directly into your HyperFrames folder.

// scripts/gen-fal.mjs
import { fal } from "@fal-ai/client";
import fs from "node:fs";

const result = await fal.subscribe("fal-ai/kling-video/v3/standard/text-to-video", {
  input: {
    prompt: "Clean minimalist developer cockpit HUD animating charts, 1080p",
    duration: "5",
    aspect_ratio: "16:9"
  }
});

const url = result.data.video.url;
const buf = Buffer.from(await (await fetch(url)).arrayBuffer());
fs.mkdirSync("assets", { recursive: true });
fs.writeFileSync("assets/fal-cockpit-broll.mp4", buf);
console.log("Saved assets/fal-cockpit-broll.mp4");
Step 04

Wire Assets in Claude Code & Preview Locally

Ask Claude Code to reference assets/fal-cockpit-broll.mp4 in your scene HTML/GSAP composition and verify immediately on localhost:3002.

# Inside Claude Code:
/hyperframes:hyperframes
"Place assets/fal-cockpit-broll.mp4 as the background layer in S04
 with a 0.6s fade-in and keep voiceover track Vo04 at 85%."

# Preview locally in browser (localhost:3002):
npx hyperframes preview
Step 05

Export on HyperFrames Pro Cloud (0% Local CPU)

Switch back to the HyperFrames Pro Studio desktop app—your new fal.ai assets and Claude edits appear live. Click Export → Render on: Cloud (1080p / 4K MP4) to use your unlimited Pro cloud exports!

Practical Engineering Notes

3 Things to Watch Out For in the Hybrid Setup

Real-world details so your fal.ai-generated files sync cleanly with HyperFrames Pro Studio and cloud exports.

1. Always Save fal.ai Outputs Inside the Project Folder

Never hotlink temporary fal.ai CDN URLs directly in index.html (they can expire). Always download generated .mp4, .png, or .wav files into a relative assets/ subfolder inside ~/.hyperframes-studio/<project>/ so Cloud Export bundles them reliably.

2. Avoid Simultaneous Edits While Framey Is Locked

When HyperFrames Studio shows Working | Locked on the timeline, pause local Claude Code edits until Framey finishes writing to avoid file conflicts on index.html or hyperframes.json.

3. Captions & Timestamps for fal.ai Voiceovers

Built-in HeyGen voiceovers automatically create .transcript.json files for subtitles. When generating TTS via fal.ai/ElevenLabs locally, ask Claude to run fal's Whisper timestamp endpoint to emit a matching JSON transcript so captions stay word-synced.
